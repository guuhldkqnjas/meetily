## 🤖 Overview

Meetily listens to your video calls and meetings, transcribes every word, and generates concise summaries with action items, saving hours of manual note-taking.

Whether you're a newcomer or a veteran, Meetily provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Live Transcription** | Real-time caption stream during any video call or meeting |
| **Smart Summary** | Auto-generated meeting summary with key decisions highlighted |
| **Action Items** | Extracts and lists assigned tasks with speaker attribution |
| **CRM Integration** | Pushes meeting notes to HubSpot, Salesforce, and Notion |
